PHASE 1: GOOGLE SPREADSHEET & APPS SCRIPT SETUP
--------------------------------------------------------------------------------
1.1 Create the New Spreadsheet:
    1. Create a blank Google Spreadsheet named: "PPMP Pharmacy Evaluation System"
    2. Name the first tab: "indicative 1" (paste your generic drug list here).

1.2 Install Code.gs:
    1. Go to Extensions -> Apps Script.
    2. Paste the entire code from Code.gs into the editor.
    3. Press Ctrl + S (Save). Name project: "PPMP Backend Engine".

1.3 One-Click Initialization:
    1. Refresh the Google Sheet (F5).
    2. Click custom menu: [🏥 PPMP Evaluation] -> [🚀 Initialize Evaluation Workbook].
    3. Grant the Google permission when prompted.
    4. Next, click:
       - [🔄 Sync Master Drug List]
       - [📊 Initialize / Refresh Horizontal Report]
       - [📑 Initialize / Reset Printable Checklist Viewer]
       - [⚡ Setup Auto-Sync Triggers]


PHASE 2: APPSHEET SETUP (CLEAN & ERROR-FREE)
--------------------------------------------------------------------------------
2.1 Connect AppSheet:
    In Google Sheets: Extensions -> AppSheet -> Create an app.

2.2 THE GOLDEN RULE (Add ONLY 4 Tables):
    1. Evaluations_Master  -> Are updates allowed? ADDS, UPDATES
    2. Medicine_Master     -> Are updates allowed? READ_ONLY
    3. Suppliers           -> Are updates allowed? READ_ONLY
    4. Consolidated_Summary-> Are updates allowed? READ_ONLY
    ⚠️ DO NOT add Evaluator 1, Evaluator 2, or Evaluator 3 as Tables!

2.3 Configure Columns (Evaluations_Master):
    - Evaluation_ID: Text, Key = YES, Initial value: =UNIQUEID()
    - Timestamp: DateTime, Initial value: =NOW()
    - Generic_Name: Ref to Medicine_Master, Label = YES
    - Price: Type = Price (Currency: ₱, Decimals: 2)
    - P1_01 to P1_19: Enum (Buttons: Yes, No, N/A)
    - P2_01 to P2_06: Enum (Buttons: Yes, No, N/A)
    - Requires_Reconstitution: Enum (Buttons: Yes, No)
    - P3_01 to P3_09: Enum (Buttons: Yes, No, N/A)
    - Remarks: LongText
    - Recommendation: Enum (Recommended, Not Recommended)
    - Data_Privacy_Consent: Enum (Buttons: Yes, No), Required = YES, Valid_If = [_THIS] = "Yes"
    - Accuracy_Consent: Enum (Buttons: Yes, No), Required = YES, Valid_If = [_THIS] = "Yes"
    - Evaluator_Signature: Type = Signature

2.4 Create the 3 Evaluator Slices (Data -> Slices -> Add Slice):
    - Slice_Evaluator1:
        Source: Evaluations_Master
        Filter: OR([Evaluator] = "End-user", [Evaluator] = "Evaluator 1")
    - Slice_Evaluator2:
        Source: Evaluations_Master
        Filter: OR([Evaluator] = "Nurse", [Evaluator] = "Evaluator 2")
    - Slice_Evaluator3:
        Source: Evaluations_Master
        Filter: OR([Evaluator] = "Pharmacist", [Evaluator] = "Evaluator 3")


PHASE 3: UX NAVIGATION & 5-PAGE FORM
--------------------------------------------------------------------------------
3.1 Set up the 5 Primary Navigation Views (Views -> Primary Navigation):
    1. New Evaluation -> Source: Evaluations_Master (Form view)
    2. Evaluator 1    -> Source: Slice_Evaluator1   (Deck view)
    3. Evaluator 2    -> Source: Slice_Evaluator2   (Deck view)
    4. Evaluator 3    -> Source: Slice_Evaluator3   (Deck view)
    5. Consolidated   -> Source: Consolidated_Summary (Table view)

3.2 In "New Evaluation" Form Column Order:
    - Page 1: Evaluator, Generic_Name, Brand_Name, Supplier, Manufacturer, Price
    - Page 2: Part I items (P1_01 to P1_19)
    - Page 3: Part II items (P2_01 to P2_06)
    - Page 4: Part III items (P3_01 to P3_09)
    - Page 5: Remarks, Recommendation, Data_Privacy_Consent, Accuracy_Consent, Evaluator_Signature
